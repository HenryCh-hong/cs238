# Annotated sample of the final report

This folder holds a **layout sample** of the final report. It is not the report.

| File | What it is |
| --- | --- |
| `report_sample_en.pdf` | The sample with notes in English |
| `report_sample.pdf` | The same sample with notes in Chinese |
| `report_sample_en.tex`, `report_sample.tex` | The LaTeX sources of the two editions |
| `figures/`, `tables/` | Figures and tables, generated by code from the saved experiment results |
| `tables/numbers_sheet.csv` | Every number the tables print and the notes quote, with its source |
| `figures/figure_numbers.csv` | The numbers shown in the two figures |
| `refs.bib`, `neurips_2024.sty` | Reference list and the style file |

## What is real and what is not

- Real: the title, the section headings, the equations, the figures, the tables and the reference list.
- Yellow boxes: instructions for one paragraph each (what it must contain, which numbers to use, which textbook
  pages to cite). They are instructions to the authors, not text of the report. The authors write every sentence of
  the report themselves.
- Blue boxes: example sentences about a different topic (a traffic light) with invented numbers. They only show a
  writing style.

The first two pages of each PDF explain how to use the sample.

## How it was made

The sample (outline, notes, layout, typeset equations, figures and tables) was made with Claude Code, an AI tool.
The two editions have the same content.

## Build

```
tectonic report_sample_en.tex
tectonic report_sample.tex      # needs the macOS font PingFang SC for the Chinese notes
```

To see the bare layout without the boxes, change `\notestrue` to `\notesfalse` in the source and build again.

The cover pages give the commands that regenerate the figures and tables. They write to a working folder outside
this repository (`../final_report`); to write into this folder instead, use `--out docs/report_sample/figures` and
`--out docs/report_sample/tables`. The two generating scripts (`experiments/report_figures.py` and
`experiments/report_tables.py`) are not in the repository yet.
